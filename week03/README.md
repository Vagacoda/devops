# 3주차 학습

- ubuntu로 Qwen, Ollama를 설치하였다.

- Qwen은 답변을 만드는 모델이다.
- Ollama는 모델을 실행하고 관리하는 로컬 서버 및 도구이다.
  또한 답변을 만드는 모델을 실행한다.
- ShellScript는 여러명령을 파일에 작성하여 같은 절차로 실행하는 스크립트이다.
  실행권한, shebang을 확인하고 실행 설정에 전달.
  환경변수로 프로그램의 실행설정에 전달.
  명령의 종료 상태로 성공의 실패 판단 가능.
  표준 출력, 표준 오류, 실패 종료 등 구분.

특히 shellscript로 qwen을 실행하는 여러 설정들을 추가 하였다.
조건문으로 프로그램 설치 여부를 알려주는 부분을 만들었다.
ex) `if ! command -v python >/dev/null 2>$1; then
      echo "파이썬3 먼저 설치하세요" >&2
      exit 1
    fi`
조건문은 if 명령어; then 실행문 fi 로 정의된다.
`command -v`는 명령을 실행가능할때 어느경로에 있는지 확인하며
없는 명령이라면 아무것도 출력하지 않고 실패상태를 반복한다.
`>`는 표준 출력을 다른 곳으로 보내는 리다이렉션이다.
`>/dev/null`은 출력을 버린다는 뜻
`2>&1`은 2번 표준 오류를 1번 표준 출력이 가는곳으로 보냄
순서에 따라 다른 해석이 됨 (왼->오)
0: 표준 입력 stdin
1: 표준 출력 stdout
2: 표준 오루 stderr
