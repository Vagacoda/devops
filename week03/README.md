# 3주차: 셸 스크립팅

## 학습 내용
- 터미널 명령어를 파일에 작성하여 순서대로 실행하는 방법을 배웠다.
- 변수와 인자를 사용해 값을 전달했다.
- 조건문과 반복문으로 상황에 따라 작업을 처리했다.

## 주요 개념
- 셸 스크립트: 여러 명령어를 파일에 모아 실행하는 것
- 변수: 값을 저장하고 `$변수명`으로 사용하는 것
- 인자: 실행할 때 전달하는 값으로, `$1`, `$2` 등으로 사용한다.
- 조건문: 조건에 따라 실행할 명령어를 선택한다.
- 반복문: 같은 작업을 여러 번 실행한다.

## 기본 예제
~~~bash
#!/bin/bash

name="${1:-사용자}"
echo "Hello, $name"
~~~

첫 번째 인자가 있으면 이름으로 사용하고, 없으면 '사용자'를 사용한다.

## 실행 방법
~~~bash
bash hello.sh User
~~~

실행 권한을 부여하면 다음과 같이 실행할 수도 있다.

~~~bash
chmod +x hello.sh
./hello.sh User
~~~

## 정리
반복해서 입력하던 명령어를 스크립트로 만들면 한 번에 실행할 수 있다.
변수, 조건문, 반복문을 활용하면 입력값이나 상황에 맞게 작업을 처리할 수 있다.
