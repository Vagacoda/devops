# 2주차: 실습 환경 구축과 Git 기초

## 학습 내용
- 실습에 필요한 환경을 준비하고 기본 터미널 명령어를 익혔다.
- Git으로 파일의 변경 내용을 기록하는 방법을 배웠다.
- GitHub 저장소와 연결하여 실습 파일을 업로드했다.

## 주요 명령어
- `pwd`: 현재 위치 확인
- `ls`: 파일과 폴더 목록 확인
- `cd`: 작업 폴더 이동
- `git status`: 변경된 파일과 현재 상태 확인
- `git add 파일명`: 커밋할 파일 선택
- `git commit -m "메시지"`: 변경 내용 기록
- `git push`: 원격 저장소에 커밋 업로드

## 정리
Git은 파일의 변경 이력을 관리하고, GitHub는 저장소를 온라인에서
보관하고 공유하는 데 사용한다.
파일을 수정한 뒤 add, commit, push 순서로 GitHub에 반영한다.
